# Enovus Labs — website

Static, dependency-free site for [Enovus Labs](https://www.enovuslabs.com), the Dublin thermal and mechanical engineering company behind Segri-COOL.

- `index.html` — the full single-page site (responsive from 360px phones to wide desktops)
- `assets/` — logo, favicon and product renders (WebP)

Deploys as-is on Vercel, Netlify or GitHub Pages; there's no build step.
